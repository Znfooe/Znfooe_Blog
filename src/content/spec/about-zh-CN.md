# 关于 Shirone

欢迎来到 **Shirone**（白音）—— 一款富有表现力、灵感源自动漫的博客主题，基于 **Material 3 Expressive（M3E）** 设计语言构建。

::github{repo="LyraVoid/Shirone"}

## ✦ 设计理念

Shirone 致力于将感性细腻的动漫美学，与严谨现代的 Web 工程巧妙融合：

- **灵动调色（Dynamic Chromatic Spell）**：整套 HCT 色板根据明暗模式与个人偏好**动态生成**，过渡丝滑，零布局抖动。
- **无缝壳层（Seamless Shell Navigation）**：由 Swup 驱动的持久应用壳层，让背景音乐不间断、页面切换无闪烁、滚动状态不丢失。
- **丰富叙事（Rich Story Grimoire）**：支持 Markdown 与 MDX 双格式撰写；KaTeX 公式、Mermaid 图表、交互式注释、表达力强的代码块、自适应图册皆在话下。
- **零多余负担（Zero Extra Burden）**：可选模块（评论 / 统计 / 音乐部件）按需**懒加载**；未启用时，**零** DOM 残留、**零** 额外包体。

## ✦ 技术栈

- **框架**：[Astro 7](https://astro.build/) & [Svelte 5](https://svelte.dev/)（基于 Runes 的岛屿架构）
- **样式**：[Tailwind CSS 4](https://tailwindcss.com/) & [Stylus](https://stylus-lang.com/)
- **设计语言**：[Material 3 Expressive](https://m3.material.io/)
- **字体**：Outfit & Yozai（悠哉圆体），构建期自动子集化裁剪
- **搜索引擎**：[Pagefind](https://pagefind.app/) 离线全文搜索
