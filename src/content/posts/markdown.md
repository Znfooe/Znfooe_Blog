# 一级标题（h1）

段落之间以空行分隔。

第二段。_斜体_、**粗体**与`等宽字体`。无序列表看起来
像这样：

- 这一个
- 那一个
- 另一个

注意——先不考虑那个星号——正文内容实际是从第 4 列
开始的。

> 引用块是
> 这样书写的。
>
> 引用块可以跨越多个段落，
> 只要你愿意。

使用 3 个连字符表示长破折号。范围用 2 个连字符表示（例如，"见
第 12--14 章"）。三个点 ... 会被转换成省略号。
支持 Unicode 字符。☺

## 二级标题（h2）

下面是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再次注意，正文内容是从第 4 列开始缩进的（距左侧 4 个
字符）。下面是一个代码示例：

    # Let me re-iterate ...
    for i in 1 .. 10 { do-something(i) }

正如你可能已经猜到的那样，缩进为 4 个空格。顺便提一句，除了
缩进整块，你也可以使用围栏代码块，如果你喜欢的话：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴会更容易）。你也可以选择性地给围栏代码块
加上语言标记，以便 Pandoc 做语法高亮：

```python
import time
# Quick, count to ten!
for i in range(10):
    # (but not *too* quick)
    time.sleep(0.5)
    print i
```

### 三级标题（h3）

接下来是嵌套列表：

3. 把所有东西倒进锅里，然后按照
    下面的算法操作：

        stir
        cover pot
        balance wooden spoon precariously on pot handle
        wait 10 minutes
        goto first step (or shut off burner when done)

再次注意，文字始终以 4 个空格缩进对齐（包括上面第 3 项
延续下来的最后一行）。
