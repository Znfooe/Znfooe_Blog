**MDX（Markdown + JSX）** 弥合了静态写作与应用界面之间的鸿沟。在 Shirone 中，作者可以直接在文章内容里无缝混排动态逻辑、响应式 Svelte 5 组件与 Material 3 设计令牌。
:::

## 1. Markdown 与 MDX 能力对照

| 特性 | 标准 Markdown（`.md`） | Shirone MDX（`.mdx`） | 执行模式 |
| :--- | :--- | :--- | :--- |
| **排版与结构** | 完整支持 | 完整支持 | 静态 SSR |
| **代码高亮** | 行号、外框、可折叠 | 行号、外框、可折叠 | 静态 SSR（Expressive Code） |
| **图表与数学公式** | Mermaid、KaTeX | Mermaid、KaTeX | 客户端增强 |
| **Callout 提示框** | Note、Tip、Important、Warning、Caution | Note、Tip、Important、Warning、Caution | 静态 SSR |
| **M3E 展示类原子组件** | 不可用 | 直接集成（`<Card>`、`<Skeleton>`） | 纯 SSR（零客户端 JS） |
| **Svelte 5 响应式交互岛** | 不可用 | 按需水合（`<Button>`、`<Switch>`） | `client:visible` 懒水合 |
| **反馈与加载原子组件** | 不可用 | 动态形变（`<LoadingIndicator>`） | `client:visible` 响应式 |
| **动态 JSX 表达式** | 不可用 | 原生求值（`{authorInfo.ui}`） | 编译期 / 客户端 |

## 2. 动态表达式与数据映射

MDX 允许在文件顶部使用 `export const` 声明作用域常量，既可在行内求值，也可在模板中做数据映射：

- **核心框架**：{authorInfo.framework}
- **UI 引擎**：{authorInfo.ui}
- **设计令牌**：{authorInfo.tokens}
- **架构模式**：{authorInfo.architecture}
